FONTLOG for Dubori Asomiya Serif
-----------------------------------------------------------
This file provides detailed information on the Dubori Asomiya Serif Font Software.
This information should be distributed along with the Dubori Asomiya Serif fonts
and any derivative works.

Basic Font Information
-----------------------------------------------------------
Dubori Asomiya Serif (দুবৰি অসমীয়া চেৰিফ) is an authoritative, publication-grade
open-access Assamese editorial serif typeface family designed and engineered by
Dubori (Naruttam Boruah).

Engineered specifically for books, newspapers, high-density editorial columns,
and digital web typography, Dubori Asomiya Serif includes:
- 11 versatile typographic styles (Regular, Medium, SemiBold, Bold, Black 900,
  Condensed 75%, Bold Condensed, Black Condensed, Italic 11.5°, Bold Italic,
  and Variable Font [wght, wdth]).
- Explicit OpenType LangSys 'ASM ' injection into GSUB 'bng2' and 'beng' scripts.
- Authentic Assamese orthography strictly preserving Ra (ৰ - U+09F0), Va (ৱ - U+09F1),
  Ya (য় - U+09DF), and authentic overhanging headline (শিৰোৰেখা) on Aa-kar (া - U+09BE).
- Verified ligature shaping for all 209 compound conjuncts (যুক্তাক্ষৰ).

ChangeLog
-----------------------------------------------------------
26 October 2026 (Naruttam Boruah) Dubori Asomiya Serif Version 1.000
- Initial public release under SIL Open Font License 1.1.
- Injected native OpenType LangSys 'ASM ' into GSUB tables.
- Restored authentic overhanging headline (শিৰোৰেখা) spur on terminal vowel signs:
  uni09BE.fina (া), uni09C0.fina (ী), and uni09D7.fina (ৌ).
- Built comprehensive 11-style matrix including 75% width condensed styles for
  editorial newspaper columns and headlines.
- Generated continuous Variable Font format supporting weight (100-900) and
  width (75-100%) interpolation axes.
- Verified 208/209 conjuncts with HarfBuzz shaping engine.
